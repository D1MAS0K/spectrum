# 🧠 ראש נקי - Rosh Naki

**אפליקציית גמילה מקנאביס של קהילת ראש נקי בהנהגת ניב איפרגן**

> "החופש האמיתי מתחיל כשאתה מפסיק לברוח מעצמך"

## מה זה?

ראש נקי היא אפליקציית מעקב גמילה מקנאביס, בהשראת I Am Sober, מותאמת לחלוטין לקהל הישראלי ולקהילת "ראש נקי" של ניב איפרגן.

## פיצ'רים

### 🕐 מונה ניקיון בזמן אמת
- ימים, שעות, דקות, שניות של ניקיון
- חישוב כסף שנחסך (בשקלים)
- חישוב שעות שנחסכו

### 📋 התחייבות יומית
- התחייבות בוקר עם מצב רוח
- סיכום ערב עם דירוג קושי
- מעקב streak (רצף ימים נקיים)

### 🏆 אבני דרך
- 11 אבני דרך מיום 1 עד שנתיים
- פס התקדמות לכל אבן דרך
- חגיגה אוטומטית בהשגה

### 🆘 כלי התמודדות עם דחפים
- תרגיל נשימה מודרך (4-4-4)
- תיעוד דחפים עם עוצמה וטריגרים
- סטטיסטיקת הצלחה

### 📋 ציר זמן גמילה מקנאביס
- 6 שלבי גמילה מפורטים
- תסמינים צפויים
- טיפים להתמודדות

### 📝 יומן אישי
- רשומות עם מצב רוח
- תיעוד המסע האישי

### 👥 קהילה
- שיתוף, שאלות, אבני דרך, בקשות תמיכה
- אפשרות אנונימית
- לייקים ותגובות
- שיתוף בוואטסאפ

### 💜 ציטוטים מוטיבציוניים
- 20 ציטוטים בעברית
- מותאמים לגמילה מקנאביס
- ציטוט יומי מתחלף

### 📱 PWA
- עובד כאפליקציה על הטלפון
- עובד אופליין
- RTL מלא

## הפעלה

```bash
# התקנה
cd rosh_naki
pip install -r requirements.txt

# הרצה
uvicorn rosh_naki.app:app --reload --host 0.0.0.0 --port 8000

# פתח בדפדפן
# http://localhost:8000
```

## טכנולוגיות

- **Backend:** FastAPI + SQLAlchemy + SQLite
- **Frontend:** HTML/CSS/JS (ללא framework - מהיר וקליל)
- **Font:** Heebo (גופן עברי)
- **Design:** Mobile-first, RTL, PWA-ready
- **צבעים:** סגול #6B2D8B (ראשי), ירוק #4CAF50 (משני)
